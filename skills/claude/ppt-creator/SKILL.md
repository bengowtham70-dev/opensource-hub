# PowerPoint Creator

## Overview

Create professional PowerPoint presentations from rough notes, outlines, documents, or ideas using structured slide design, storytelling, and presentation-focused formatting.

## When to Use

- Creating business presentations
- Building startup pitch decks
- Preparing technical presentations
- Summarizing reports into slides
- Creating educational content
- Converting notes into structured presentations

## Design Principles

**CRITICAL**: Before creating any presentation:

1. **Consider subject matter**: What tone, industry, or mood does it suggest?
2. **Check for branding**: Use company brand colors if mentioned
3. **Match palette to content**: Select colors that reflect the subject
4. **State your approach**: Explain design choices before writing code

## Core Presentation Rules

### 1. Slides Support the Speaker
- Summarize information
- Reinforce key points
- Support storytelling
- **AVOID**: Paragraph-heavy slides, excessive text

### 2. Visual Hierarchy
- Strong headings
- Concise bullets
- Proper spacing and alignment
- Progressive information flow

### 3. Keep Content Concise
- One major idea per slide
- Remove filler content
- Emphasize key takeaways
- Avoid large text blocks

### 4. Narrative Structure
Typical flow:
1. Title
2. Overview/Problem
3. Context
4. Solution
5. Results
6. Next Steps
7. Conclusion

## Typography

- Use web-safe fonts: Arial, Helvetica, Times New Roman, Georgia, Courier New, Verdana
- Create clear visual hierarchy through size, weight, and color
- Minimum 24pt for body text, 36pt+ for headings
- Ensure readability: strong contrast, appropriately sized text

## Layout Guidelines

- Two-column layout (PREFERRED) for charts/tables with text
- Full-slide layout for maximum impact
- **NEVER vertically stack** charts below text
- Use consistent spacing across slides
- Leave white space for readability

## Workflow

1. Analyze source material and identify key points
2. Define presentation structure and flow
3. Generate concise slide content
4. Improve visual hierarchy
5. Add presentation flow and transitions
6. Validate readability and consistency

## Best Practices

- One major idea per slide
- Keep text concise (6-8 lines max)
- Use strong headings
- Maintain consistent formatting
- Prioritize storytelling flow
- Design slides to support the speaker
