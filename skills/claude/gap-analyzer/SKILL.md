# Gap Analyzer

## Overview

Systematic approach to identifying gaps between current state and desired goals across code, content, requirements, and processes.

## When to Use

- Comparing current vs desired state
- Identifying missing features or functionality
- Finding discrepancies in code or content
- Analyzing requirements coverage
- Evaluating skill gaps
- Assessing documentation completeness
- Reviewing test coverage

## Gap Analysis Framework

### Step 1: Define the Baseline
- What is the current state?
- What do we have now?
- What is working correctly?

### Step 2: Define the Target
- What is the desired state?
- What should we have?
- What does success look like?

### Step 3: Identify Gaps
- What is missing?
- What needs to be added?
- What needs to be changed?
- What needs to be removed?

### Step 4: Prioritize
- Critical gaps (blockers)
- Important gaps (should fix)
- Nice-to-have gaps (could improve)

### Step 5: Create Action Plan
- Specific tasks to close each gap
- Dependencies between tasks
- Estimated effort
- Timeline

## Analysis Types

### Code Gap Analysis
- Missing error handling
- Incomplete implementations
- Missing tests
- Security vulnerabilities
- Performance issues
- Documentation gaps

### Content Gap Analysis
- Missing information
- Outdated content
- Inconsistent messaging
- Missing visuals
- Incomplete explanations

### Requirements Gap Analysis
- Unimplemented features
- Missing acceptance criteria
- Undocumented requirements
- Edge cases not covered

### Skill Gap Analysis
- Current skills vs required skills
- Training needs
- Knowledge gaps
- Competency requirements

## Output Format

```
## Gap Analysis Report

### Current State
[Description of what exists]

### Target State
[Description of what should exist]

### Identified Gaps

#### Critical Gaps
1. [Gap description] - Impact: [High]
2. [Gap description] - Impact: [High]

#### Important Gaps
1. [Gap description] - Impact: [Medium]
2. [Gap description] - Impact: [Medium]

#### Nice-to-Have Gaps
1. [Gap description] - Impact: [Low]

### Recommendations
1. [Action item]
2. [Action item]

### Summary
Overall assessment of gap severity and recommended approach.
```

## Tools & Techniques

- Checklist comparison
- Feature matrix comparison
- SWOT analysis
- Root cause analysis
- Impact assessment
- Risk evaluation

## Best Practices

- Be specific and measurable
- Prioritize by impact and effort
- Document assumptions
- Include stakeholders
- Review and validate findings
- Create actionable recommendations
