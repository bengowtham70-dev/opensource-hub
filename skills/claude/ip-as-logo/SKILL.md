# IP as Logo

Create the simplest possible cute IP mascot character: a compact, lovable symbol that remains recognizable even at small icon resolutions (`32 × 32`).

## Workflow

1. **Context & Metaphor Inference:**
   - Inspect the product docs, repository metadata, and brand tone.
   - Propose 3 distinct IP mascot directions tied to the brand promise: `<IP subject> — <product connection> — <defining silhouette>`.
2. **Design Constraints:**
   - **Shapes:** Build one dominant silhouette from roughly 4–7 large basic geometric shapes. Merge or remove any shapes that do not contribute to core character identity.
   - **Forms:** Thick, heavy, rounded forms with soft neo-skeuomorphic volume and subtle tactile depth.
   - **Color Harmony:** Exactly three semantic colors:
     - 2 purposeful IP base colors for the character.
     - 1 solid, slightly muted background color filling the entire square canvas.
   - **Composition:** Dominant character emerging from the lower-left or lower-right corner.
3. **Generation:**
   - Generate candidates as separate, full-resolution square images.
   - Never generate multiple characters on a single contact sheet.
