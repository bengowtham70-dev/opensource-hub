# Landing Pages

## Rules

- Hero section above the fold: headline (benefit-driven), subheadline, primary CTA, hero image/illustration
- Single primary CTA per section — don't split attention with multiple competing actions
- Social proof near CTAs: testimonials, logos, user counts, ratings
- Section rhythm: hero → problem → solution → features → social proof → pricing → final CTA
- Mobile-first layout — hero text before image, stacked sections, thumb-friendly CTAs
- Performance: optimize hero image (WebP, proper sizing), lazy-load below-fold content
- SEO: `generateMetadata()` with target keyword in title, description, and H1
- Minimal navigation — reduce exit points, sticky CTA on scroll

## Avoid

- Hero carousels/sliders — they hurt conversion and performance
- Multiple CTAs with equal visual weight — one primary, rest secondary
- Stock photos that don't match the product — use screenshots or custom illustrations
- Walls of text — use bullet points, icons, and whitespace
