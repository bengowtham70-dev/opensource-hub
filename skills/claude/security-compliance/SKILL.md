# Security Compliance

Compliance validation and security auditing across SOC2, HIPAA, and GDPR frameworks.

## Workflow

1. Read `agents/security-auditor.md` for the security auditor agent prompt.
2. For compliance checks, follow `commands/compliance-check.md`.

## Key Rules

- Assess vulnerability posture, threat models, and OWASP standards.
- Validate compliance against SOC2, HIPAA, and GDPR.
- Check for hardcoded secrets and insecure configuration.
- Document findings with actionable remediation steps.
