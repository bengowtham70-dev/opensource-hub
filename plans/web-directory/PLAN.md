## Architecture lock â€” why static, not Next.js

The $0 rule (PRD Â§5) forbids servers we operate. OpenAlternative runs a hosted Next.js
app + DB + ad platform; our equivalent ships as **pre-rendered static HTML generated by
a zero-dependency Node script** (`scripts/build-web-directory.mjs`) that reads the SAME
`src/data/*.json` + snapshot files the local daemon reads â€” one source of truth, zero
drift between dashboard and website. Output goes to `web-dist/`, deployed free on
GitHub Pages (same host as the landing page), rebuilt daily by the existing snapshot
cron (PRD Â§35 "rides existing sync work"). No framework, no node_modules additions to
the shipped package, fully unit-testable generators.
