# OpenSource Hub — Phase 3 Plan (PRD §19 Phase-3 Scope)

> Status: **PLANNED — gated on real traction.** PRD §6.3/§19 is explicit: Phase 3 features wait
> until Phase 1+2 have real users. This document freezes the build order so execution can start
> the moment the traffic gate opens. Phase 2 (10/10 phases) shipped 2026-08-24.
>
> **Traffic gate (all three required before P1 below starts):**
> - [ ] Real GitHub repo public + first npm publish live
> - [ ] ≥1,000 monthly dashboard runs (local counters aggregated opt-in, or npm download counts)
> - [ ] Launch channels executed: Product Hunt, HN, r/opensource, r/selfhosted (PRD §11)

**Design lock:** DESIGN.md v1.1.0 tokens verbatim. **Architecture lock:** $0 central infra holds
except where PRD §21.4 explicitly budgets AI API cost for the paid tier.

## The 10 Phases

### Phase 1 — Trust Score Pro (paid tier) — PRD §6.2
- [ ] Free/Pro feature split: free = maintenance + red flags (current); Pro = full signal
      breakdown history, 90-day trust trend charts, unlimited saved audits
- [ ] Historical trust snapshots ride the existing daily Actions cron (extend snapshots.json)
- [ ] License-key-free local unlock via GitHub Sponsors webhook + signed token file
- [ ] Exportable comparison report (PDF/CSV) — PRD §20, attaches to procurement tickets
- Skills: stripe-founder-monetization (checkout), charts

### Phase 2 — AI Tool Finder (flagship paid feature) — PRD §21
- [ ] Natural-language task → ranked shortlist (curated catalog first, GitHub live search second)
- [ ] Serverless proxy holds the API key (Cloudflare Workers free tier) — the ONE piece of
      real infrastructure; cost-test before free-tier allowance ships (PRD §21.6)
- [ ] Free tier 3-5 searches/mo; Pro unlimited + deeper multi-source research
- [ ] "Why this one" reasoning pulls Trust Score + license + self-host difficulty data
- Skills: llm-integration, prompt-engineering-patterns, rag-implementation

### Phase 3 — Referral program (AI-search credits) — PRD §24
- [ ] Credits not cash (self-limiting cost, PRD §24.2); opt-in only; contextual placement
      near the AI Tool Finder
- [ ] Anti-fraud: referred account must use ≥1 search before either side is credited
- [ ] Credit amount decided from REAL per-query cost after Phase 2 usage data
- Skills: state-management

### Phase 4 — Affiliate wiring — PRD §6.1a (applications are a HUMAN action, already overdue)
- [ ] Deep-link affiliate IDs into "how to run this" notes + one-click deploy buttons
- [ ] Track per-program conversion (local attribution table; no network unless telemetry opt-in)
- [ ] TCO calculator with per-plan specificity (PRD §3a: "Auth0 B2B at $800/mo" pattern)

### Phase 5 — Watchlist & custom alerts — PRD §3 + §22
- [ ] Follow a paid tool → notify when a better alternative appears or trust score drops
- [ ] Local notifications (dashboard badge + optional OS toast); no email backend in P5
- Skills: notification-system

### Phase 6 — Weekly digest email — PRD §27.2
- [ ] Static digest generated by the weekly Actions cron (top 5 trending, new alternatives,
      trust alerts) committed as HTML; subscription via a free tier (Buttondown/Listmonk)
- [ ] Sticky newsletter capture on the public web directory pages
- Skills: cicd

### Phase 7 — Team/company mode (B2B) — PRD §20
- [ ] Stack audit: paste paid-tool list → report of viable alternatives across all of them
- [ ] Exportable report (same PDF/CSV engine as Pro), shared team lists, audit trail
- [ ] This is the B2B revenue ceiling (PRD §6.2) — price after 5 design-partner interviews
- Skills: dashboard-design, spreadsheet-export

### Phase 8 — Verified maintainer badge (2nd revenue source) — PRD §22
- [ ] "Claim this repo" (free) ships FIRST — verification loop via repo commit/README token
- [ ] Paid badge + listing analytics (views, click-throughs) charges the project, not the user

### Phase 9 — Sponsored placement — PRD §6.1
- [ ] Clearly labeled, never affects ranking (anti-manipulation rule PRD §3b)
- [ ] Silver slot (feed banner) + Platinum (sticky header) with transparent impression tracking

### Phase 10 — Programmatic SEO completion — PRD §25
- [ ] `/alternatives/[paid-tool]` hubs + `/[tool-slug]` pages on the public directory
- [ ] Dynamic OG images (`/api/og`), RSS feeds, JSON-LD on every public page
- [ ] Comparison-page content depth pass (real titles, meta descriptions, 300+ words)
- Skills: programmatic-seo-engine, landing-pages
