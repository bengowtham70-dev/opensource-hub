# GitHub in two minutes

GitHub is the world's largest collection of source code. Every tool listed in this app lives there as a **repository** ("repo") — a project's folder containing its code and history.

## The numbers that matter

- **Stars** — bookmarks. Popularity, not quality or safety.
- **Contributors** — how many people have submitted changes. More usually means more resilient.
- **Last commit** — the last time the code changed. Recent is healthy; two years ago is a warning.
- **Releases** — packaged, downloadable versions of the software (the ones you can double-click).

## What a "fork" is

Anyone can copy a repo and continue independently — that copy is a fork. If an original project dies, a fork can carry on.

## Why we don't trust star counts alone

Stars can be bought and inflated. A repo with 50k stars and no commits since 2023 is a museum piece, not a tool. That's why every listing here pairs popularity with maintenance signals.
