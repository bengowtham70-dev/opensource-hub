Stop renting software. Own it free.

One command installs a local dashboard of free, open-source alternatives to the paid tools you already use — with trust signals on every repo.

$ npm install -g opensource-hub

Requires Node.js 18+ — you probably have it. To remove later: npm uninstall -g opensource-hub

Standalone binaries (.exe / .dmg / AppImage) ship on each GitHub Release — no Node required.

What you get

Everything runs on your machine.

No account, no API key, no cloud. The app reads public GitHub data and serves a private dashboard in your browser.

Stuck?

Common install issues

macOS / Linux: "EACCES permission denied" during install

Global npm installs may need elevated permissions. Preferred fix — make npm own its folder:

mkdir -p ~/.npm-global && npm config set prefix ~/.npm-global

Then add ~/.npm-global/bin to your PATH. Avoid sudo unless you must.

Windows: "opensource-hub is not recognized"

Your npm global bin folder isn't on PATH. Run npm config get prefix, add the printed path's bin (or the folder itself on Windows) to your PATH, then reopen the terminal.

Port 3000 is already in use

Nothing to do — the app detects it and starts on the next free port automatically, printing the address it used.

Don't have Node.js at all?

Install it from nodejs.org (LTS version), then come back and run the command above.
